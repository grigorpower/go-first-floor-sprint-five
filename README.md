# Описание проекта

Разработан программный модуль фитнес-трекера, который обрабатывает данные для трех видов тренировок: бега, ходьбы и плавания.

Программа позволяет:
1. Рассчитать результаты тренировки.
2. Вывести информационное сообщение о результатах тренировки.

Информационное сообщение включает следующие данные:
1. Тип тренировки (бег, ходдьба или плавание).
2. Длительность трениовки. 
3. Дистанция, котору преодолел пользователь, в километрах.
4. Среднюю скорость на дистанции, в км/ч.
5. Расход энергии, в килокалориях. 

P.S. Модуль фитнес-трекера разрабатывался на протяжении нескольких спринтов, поэтому при отображении изменений в коммите отоборжена не вся информация.
